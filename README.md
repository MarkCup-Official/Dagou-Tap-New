# 大狗 Tap

一个可以点击发声、演奏旋律、导入音频和自动听音复唱的纯前端互动网页。

项目不需要后端服务。网页、声音分析和麦克风录音都在浏览器本机运行。

## 在线运行

直接部署为静态网页即可。麦克风功能需要运行在以下任一环境：

- HTTPS 网站
- `http://localhost`
- `http://127.0.0.1`

直接双击 `index.html` 时，部分浏览器可能禁止麦克风或模块加载，因此推荐使用本地静态服务器。

例如：

```bash
python -m http.server 7777
```

然后访问：

```text
http://127.0.0.1:7777/
```

## 相对原始版本新增的功能

原始版本位于 `D:\11\大狗叫\123123\Dagou-Tap-New-main`。本版本保留原有点击发声、角色切换、钢琴模式、视觉特效和设置功能，并增加了以下内容。

### 1. 唱歌与 MIDI 演奏

- 新增独立的“唱歌”面板。
- 支持内置 MIDI 歌曲。
- 支持导入 `.mid` 和 `.midi` 文件。
- 可以选择参与演唱的 MIDI 通道。
- 可以跳过打击乐通道。
- MIDI 音符会映射到角色的三个声音，并按照音高连续演唱。

### 2. 音频文件主旋律识别

- 支持导入 MP3、WAV、M4A、AAC、OGG、FLAC 等浏览器可解码音频。
- 支持从部分 MP4 容器中提取 AAC 音轨。
- 使用本地主旋律分析识别音高、节奏和停顿。
- 包含精确音高分析与混音增强回退方案。
- 分析结果转换为三个音节循环演唱。
- 音频最长限制为 10 分钟，避免浏览器占用过多内存。

### 3. 麦克风自动复唱

- “复读”开关位于“唱歌”按钮旁边，默认关闭。
- 开启后申请麦克风权限并自动等待声音。
- 检测到讲话或唱歌时自动关闭背景音乐。
- 连续安静约 1.2 秒后自动结束当前句。
- 单句最长约 20 秒。
- 识别当前句的音高和节奏后，大狗使用三个声音唱出相同旋律。
- 不播放、不保存、也不上传麦克风原始录音。
- 唱完或识别失败后自动恢复背景音乐，并继续等待下一句。
- 关闭开关会停止麦克风和当前复唱。

### 4. 可访问性与状态反馈

- 主要操作使用原生按钮。
- 开关提供 `role="switch"` 和选中状态。
- 文件分析、录音和复唱状态通过实时状态区域反馈。
- 支持键盘焦点和清晰的按钮标签。

## 使用方法

### 普通点击

进入网页后点击画面开始，再点击不同区域触发角色声音。

### 导入歌曲或音频

1. 点击“唱歌”。
2. 选择 MP3、其他音频或 MIDI 文件。
3. 等待本地分析完成。
4. 点击“播放”开始演唱。
5. 点击“重置”停止并清空当前内容。

### 自动复唱

1. 点击顶部“复读”开关。
2. 第一次使用时允许浏览器访问麦克风。
3. 对着麦克风说话或唱歌。
4. 停顿后等待大狗自动唱出识别到的旋律。
5. 再次点击“复读”即可关闭。

## 项目结构

```text
.
├─ index.html             页面、样式和界面结构
├─ main.js                交互、声音、MIDI、录音与自动复唱逻辑
├─ audio-data.js          内置声音数据
├─ audio-melody.js        音频主旋律和音高分析
├─ builtin-midi.js        内置 MIDI 歌曲
├─ audio/                 原始声音资源
├─ Image/                 图片和角色资源
├─ lib/                   浏览器运行所需的 MIDI/MP4 模块
├─ docs/                  开发说明
└─ tools/                 构建与验证工具
```

## GitHub Pages 部署

1. 将本目录内容上传到 GitHub 仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择从分支部署。
4. 选择包含这些文件的分支和根目录。
5. 保存并等待 GitHub Pages 生成 HTTPS 地址。

HTTPS 部署完成后，麦克风功能可以正常申请权限。用户仍需在浏览器中主动允许麦克风。

## 隐私说明

导入的音频和麦克风录音只在当前浏览器标签页中处理，不会由本项目上传到服务器。关闭自动复唱、刷新页面或关闭标签页后，临时录音不会保留。
